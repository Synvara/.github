# Synvara shared defaults

Concise issue forms and a pull request template for Synvara repositories.

- Feature, Bug, Refactor, Chore, and Docs describe a deliverable.
- Research answers a bounded question.
- Epic groups related deliverables using GitHub sub-issues.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the writing standard, branch names, and manual or agent workflow.

This repository is public so GitHub can use its community defaults for public and private Synvara repositories. A repository with its own issue templates or issue-template configuration uses its local collection instead; GitHub does not merge it with these forms. Workflows and agent instruction files are not inherited automatically.

The forms capture the initial problem and outcome. They do not grant approval or create an executable agent handoff. Approved intent and specification stay on the target issue; the implementation plan is a linked comment. Shared tooling is maintained separately in Synvara/development-workflow.

Do not put project-specific plans, credentials, customer data, or internal infrastructure details here.
